## 目标与依据

让用户进入后立即理解“提出创作需求 → 查看结果 → 在画布继续设计 → 回到项目”。以 ChatGPT 的稳定侧栏、低噪音页头、居中输入区、开放式助手回复、底部身份菜单和分栏设置为基准，服务于中文商品图与电商创作。

保留 Gouo 品牌和已经认可的 assistant-ui、官方 Excalidraw、Loomic 原生工作台。保留主要工作入口，不复制没有实现的语音、GPT 商店、订阅、支付成功、云同步或视频剪裁。视频生成仍是后续任务。

本轮实际读取 [ChatGPT 公共页面](https://chatgpt.com/)：新聊天/搜索、图片入口、底部登录、主区标题和输入、设置等信息层级。Windows 浏览器界面控制因无法可靠确认当前网址被工具停止，本轮不宣称捕获了新的 ChatGPT 登录态截图。已有参考位置见 [WORKSPACE-NAVIGATION.md](WORKSPACE-NAVIGATION.md)，只作既有设计来源；当前 Gouo 的改前、改后证据通过隔离本地浏览器测试重新捕获，不能拿旧截图替代新验收。

## 统一视觉规范

- 主面白色/深色中性背景，侧栏轻灰；不引入渐变海报、营销卡片或新的颜色体系。重点用字重、空白和选中底色表达。
- 桌面侧栏约 250–260px，手机沿用现有 Sheet 抽屉。主要动作目标至少 36px，触屏尽量 40–44px；键盘 focus-visible 明确。
- 页头约 52–56px；编辑器内工具条按其原生能力保留。标题 24–30px，正文 14–16px，辅助信息 12–13px，不使用低对比度细字表达错误。
- 对话内容不铺满主区；输入区与消息共用宽度，长文字/代码/图片各自正确折行或局部滚动。空态只有一个明确标题与主要动作。
- 设置沿用 Base UI Dialog/Menu，不能用手写浮层替换焦点和键盘机制。项目重命名如改 Dialog，复用已安装组件，不加依赖。
- 文案面向创作者：说明当前能做什么与数据存放在哪里。保留费用、未知结果、存储失败等决定用户行动的事实；将框架名和冗长协议说明降低为辅助信息。
