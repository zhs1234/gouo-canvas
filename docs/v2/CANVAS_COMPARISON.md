# 官方画布候选与旧项目保护

## 选择及产品边界

`/studio/canvas-lab` 是可以实际编辑的官方 Excalidraw 0.18.1 候选入口，复用现有 MIT 依赖，不引入第二个引擎。默认 `/studio/` 仍为 Loomic 创作工作台；实验入口不是默认引擎替换、云项目迁移或付费生图入口。

原包装层隐藏了原生菜单、工具栏、属性面板和底部控件，图层锁定/显隐按钮尚为空操作，复制逻辑仅浅拷贝元素。官方入口通过局部样式恢复原生控件，以实际编辑和同一文档比较体验；不把包装层缺口归因于 Excalidraw 本身。现阶段候选改善编辑控件完整度，但尚未接入 Loomic 的聊天、生图结果与项目库协作，因此不宜直接取代默认入口。

## 存储与只读导入

- 候选使用独立 IndexedDB `gouo-canvas-lab-v1` / `documents`，按当前 `local:guest` 或 `local:<账号ID>` 前缀存储。账号切换会卸载旧编辑器。此前无 scope 的实验 `active` 只作为访客兼容读取源保留，不覆盖它。
- 旧 Loomic 格式由 `loomic/lib/local-drafts.ts` 定义：默认 `keyval-store` / `keyval` 内的 `gouo:loomic:v1:<owner>:<canvasId>`，值为 `{ canvas, sessions, messages, thumbnail?, updatedAt? }`。画布内容为原生 `elements/appState/files`，并非 Fabric JSON。
- “查看旧草稿（只读）”先检查数据库是否存在，再用 `readonly` 事务读取当前 scope。没有旧库时不创建；不展示其他账号或访客的草稿，不修改原 key。浏览器不支持数据库枚举时，提示使用原画布导出文件。
- “导入文档副本”接受原生 `.excalidraw` 或明确识别的 Loomic Draft JSON；不接受 Fabric `objects` 格式。缺失活动图片的内嵌文件、无法恢复的元素会拒绝，不把缺损场景静默显示为成功迁移。
- 导入使用一个实验库事务写入原始 JSON、导入快照、导入前场景备份及新 active。数据库直接复制还以 `sourceDraft` 保存完整 structured clone，包括缩略图 Blob；原始 JSON 文件则逐字保留。SDK 恢复后的标准化内容不覆盖导入快照。
- “下载原始导入文件”下载最后一次导入的原 JSON。旧 IndexedDB 草稿本来没有 JSON 字节：其下载是 JSON 表示，Blob 会表示为 `{}`；Blob 的完整副本仍在实验库 `sourceDraft`，原库也不变。不能将此 JSON 下载宣称为含二进制缩略图的完整项目备份。
- 会话与消息保留于原草稿及完整快照，不迁入候选聊天界面。文档副本只承担画布交换；PNG 是视觉输出，不能用于恢复可编辑对象。

图片使用内嵌数据；固定的蓝色测试素材明确为合成 fixture，不调用模型。按 `artifactId` 去重只验证素材插入契约，不代表已对接真实生成工作流。

## 验收方式

`v2/tests/canvas-lab.pw.mjs` 使用合成素材、隔离浏览器上下文和本地 API 拒绝响应。覆盖：

1. 官方矩形、文字、撤销/重做；图片拖放与 ClipboardEvent 粘贴。
2. 图片选择、缩放、旋转、删除和撤销，以及导出、保存重开后的原始图片字节一致性。
3. 原生图片裁剪、crop 元数据保存重开，原始图片文件不变。
4. 文档副本恢复、未知附加字段原始快照、Fabric 拒绝与缺图失败保留原场景。
5. 当前 scope 旧草稿可见、其他 scope 不可见、旧数据库零写入、不存在旧库不创建、旧消息/缩略图完整快照。
6. PNG 输出签名与 Excalidraw 文档文件恢复。

运行：`cd v2 && npm run test:e2e -- tests/canvas-lab.pw.mjs --workers=1`。该文件包含 9 项浏览器测试。ClipboardEvent 是对原生粘贴处理器的合成事件验证，不等同跨应用系统剪贴板联调。操作系统文件选择器在此前 headless 环境未触发 Playwright filechooser；拖放文件路径已覆盖，系统选择器仍需交互浏览器验收。无真实供应商或付费调用。

## 默认入口准入与回退

默认切换前还需满足：

- 实际生成素材和聊天引用通过统一业务接口插入候选画布，错误、取消与迟到结果不会串项目；不是仅靠 fixture 插入。
- 产品项目列表、名称、账号转换、明确保存状态及备份恢复闭环与当前入口等价；定义聊天与画布的关系，避免导入时误认为会话已迁移。
- 代表性中文文字、组/箭头绑定、裁剪图片、复杂场景及实际用户导出文件完成视觉比较；没有采用 Fabric 自动转换。
- 多标签并发与保存失败提示、关闭窗口尚未写完的草稿、容量压力和移动端控件完成验收。当前保存是本地异步写入，不是持久任务或跨设备同步。
- 本机 scope 是产品显示隔离，不是共享设备加密保护；原生素材库的外部交互、系统图片选择器及浏览器剪贴板权限单独验证。

回退无需数据库迁移：继续使用 `/studio/`，原 Loomic keys 未改变。需要移回候选编辑结果时先导出 `.excalidraw`，在支持导入的编辑器中验证副本；不要覆盖旧 Draft 或声称导出包含全部会话。若将来关闭候选入口，应保留实验库并提供导出机会，不自动删库。
