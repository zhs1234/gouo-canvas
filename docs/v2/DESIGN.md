# 页面与工作流约定

## 当前页面

用户选择成熟 Loomic 前端：进入 `/studio/` 直接打开无限画布，右侧是原生智能体聊天，底部为浮动工具栏与缩放/图层控制。复用原项目的布局、图标、附件选择、消息/工具结果样式，不重新包一层 dashboard。桌面聊天可拖动调宽，移动端默认收起，点击“对话”打开覆盖面板。

左上角是项目菜单与名称，右上角提供本地保存与 New API 账号。项目菜单进入本地项目列表、创建/删除项目、导入图片、撤销/重做和导出；明确“本地创作”，不显示云同步成功。项目和聊天按当前访客/账号分组，登录不自动迁移访客草稿。

图片生成面板由服务端能力目录控制；待配置模型禁用，无通用 provider/key 输入。实际配置缺失和登录错误必须展示真实原因，不生成示范图片冒充 AI 输出，不补假余额或充值按钮。保留视频展示结构，视频生成入口禁用，视频剪裁不实现。

## 编辑与保存

Loomic/Excalidraw 负责图形、文字、图片、变换、图层、平移/缩放。当前浏览器内保存画布/附件/对话，可恢复项目并导出 PNG/Excalidraw 文档；清理站点数据会丢草稿。快速关闭页面不保证异步写入完成，重要修改显式保存并导出。模型请求是 HTTP 返回事件批次，取消仅停止浏览器等待，不能承诺取消上游收费。

核心界面优先中文，保留上游名称/模型名称。异步打开画布需等待 hydration 后才允许保存，避免空场景覆盖。账号和项目切换应关闭旧编辑实例，避免旧内容写入新的草稿。

## 后续电商工作流

上传商品 → 选择主体保护方式 → 选择场景/模板 → 提示预计权益用量 → 持久化后台任务 → 选择结果 → 修改文字/Logo → 保存/导出。该产品流程在 B3/S1/W1 实现，当前不显示假任务队列或收费成功。

商品、背景、标题、价格、卖点与 Logo 应独立图层；促销文字用户确认，模板批量填数据。严格保留商品时，优先抠图后只生成背景再合成。图片生成尺寸和排版导出尺寸分离，尺寸预设可编辑；未经核验不标为平台官方规则。

## 质量与可用性

保留原生工具交互与键盘支持；输入、保存、导出、登录/配置失败有可见反馈。移动端保证画布、聊天和下载不溢出。测试本地导入→保存→刷新→导出、项目切换、账号切换、聊天结果恢复与错误处理。

素材仅使用有授权的样例，不提交客户图、系统字体或生成结果。字体与许可证见 LOOMIC.md；真实商品图质量和模型能力仍须渠道实测。
