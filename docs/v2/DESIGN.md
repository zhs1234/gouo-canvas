# 页面与工作流约定

## 用户路径

工作台：按“商品主图、白底图、换背景/场景图、商品海报、批量图片”进入。商品图资产可复用，项目组织而不是无限图库。普通模式隐藏供应商、Key、CFG、HTTP 参数；高级模式只显示当前模型已验证的选项。

场景图：上传商品 → 选择商品主体保护方式 → 选择场景/模板 → 提示预计额度 → 后台任务 → 结果选择 → 编辑文字/Logo → 保存项目 → 导出。需要严格保留商品时，优先抠图后只生成背景再合成；不要宣称生成模型保证商品外观绝不改变。

工作台展示最近项目、进行中任务、额度摘要。模型目录由服务器控制且只列可用能力；模型不支持某操作时给出原因和用户确认的替代，不偷偷改结果规格。

## 编辑器

Fabric 负责图形对象/变换/渲染。Gouo 负责模板字段、图层面板、撤销重做、品牌素材、版本化文档与权限。当前 starter 的本地图片/文字/删除/导出不是完整编辑器。

商品、背景、标题、价格、卖点、Logo 独立图层。促销文字用户确认后再导出。批量输出用同一个模板填数据，不让每张重新输入 prompt。语言和数字格式独立配置，为外贸/社媒保留多语言字段。

布局：桌面左导航 + 主工作区；编辑器主画布 + 上下文工具；移动端先保证选图、任务查看与下载，不强行塞完整专业编辑器。异步加载有明确状态，按钮不能假装成功。

## 导出预设

平台尺寸先作为可编辑 presets（如 square/portrait/landscape），附来源、更新时间和用途。未经平台最新规则核验，不把任意像素值标成“官方要求”。模型生成尺寸与最终排版导出尺寸分离，避免直接拉伸商品；裁剪、留白与重排策略需用户可控。

## 质量与可用性

有空状态、未登录、缺配置、任务排队、失败恢复、部分成功、额度不足、订阅到期、文件超限提示。批量任务显示逐项结果与失败原因。页面键盘操作、标签、焦点、加载/错误提示可访问。

测试素材只使用有授权的样例；不要把用户上传、生产客户图或系统字体提交进公开仓库。模型营销能力不等于质量验收，建立真实商品样本回归清单。
