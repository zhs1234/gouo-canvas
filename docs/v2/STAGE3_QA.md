# 第三阶段验证报告

测试范围：授权分支上的项目/原图持久化、assistant-ui 图片操作、官方 Excalidraw 联动、普通模型路由保护。未配置真实账号/token/渠道，未调用真实供应商；测试不会改生产实例。最终远端精确 SHA 与 CI 链接记录于交付回复及 STATUS。

## 本地验证及证据含义

- `npm run check`：类型、14 领域、53 API、Vite 生产构建。项目 API 测试覆盖 owner404、非法客户端来源/图片、并发来源幂等、CAS、失败/unknown已知图片、像素及完整解码、SQLite重启和停服备份副本恢复；路由7项覆盖证据拒绝、未带后缀普通token、503/断线只尝试一次、非秘密checker不读取继承秘密环境。
- 浏览器最终套件42项：原账号/旧画布/流式测试保留；9官方画布、6服务器项目、10assistant-ui聊天（3新增图片操作）。包括裁剪原图、删除后刷新不复活、CAS/503暂停和恢复副本、历史重复工具只一图、存储失败原图保留且不重生成、选择既有项目。
- `npm run test:stack`：第一轮真实固定NewAPI但未初始化，零root/匿名/生成关闭/Origin/v1边界；第二轮2项明确内存网关替身，真实edge/API/SDK/SQLite及浏览器，含聊天生图→素材→项目→官方画布→项目库、刷新及其他owner404。不能据此宣称真实NewAPI登录、渠道、供应商或计费已验证。
- `npm ls --all`有效；完整/omitdev audit均0。没有新增依赖/锁文件，保留已有许可声明及固定源码链接。
- `node scripts/check-model-config.mjs`默认禁用样例通过。示例未核验normal-routing证据预期拒绝；不会访问网络、key/.env或配置账户。

## 过程中失败及处理

1. 并行Playwright命令复用了同一个5174测试启动器，一个清理后另一个出现connection refused。停止并行同端口测试、所有子任务编辑冻结后由根任务串行完整验收；不是应用已复现崩溃。
2. 同时整栈Docker构建及2worker浏览器负载下，5秒初始化断言和旧画布停止后立即刷新有时失败。独立串行19项复验全部通过；最终完整42项与CI使用单worker、不与构建竞争。旧画布异步本地写入没有突然关闭最后片段的保证，该限制保留；服务器项目保存有明确确认及恢复副本。
3. 整栈断线测试替身token间隔25ms，受调度影响首次reader.read偶尔收到含run.completed的合并包，未真正测试到断线。对明确“断线恢复”fixture加入每块1秒间隔，保持必须在terminal前断开断言；其他请求仍25ms。这是测试替身时序修正，未修改生产SDK或重试。

失败日志/上下文曾保存执行器 /tmp 与test-results（可再生成，不作为新环境依赖）。实际产品限额/生产安全等未覆盖的项见HANDOFF、MODEL_SETUP、CANVAS_COMPARISON；未将测试替身与真实系统结论混写。
