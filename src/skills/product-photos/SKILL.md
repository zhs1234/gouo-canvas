# 产品图与电商图

核心原则：**产品来自真实照片，画面只重建产品周围的场景**。产品的造型、颜色、Logo、标签、结构和比例在每一张图里都保持一致。

## 1. 先拿到真实产品图

- 先看用户在对话里上传的附件（系统提示里的参考图片 ID），关联了画布时也可以用 `get_canvas()` 查找画布上的产品图。没有产品图时，先请用户上传，**不要凭文字描述凭空造一个产品**冒充真实商品。
- 用户明确只要“概念产品”“设计提案”时可以纯文字生成，但要说明这不是实物照片。
- 看清产品后，在心里记下“产品锁定清单”：品类和形态、轮廓、主色和材质、Logo/标签位置、开合部件和当前状态（盖着/打开）、比例。

## 2. 最多问 4 个问题

需求已经清楚时跳过提问。否则一次性问完，最多 4 个，并允许用户自由回答：

1. 产品是什么、有什么关键特征（只在没有图时问）
2. 品牌规范：品牌色、不出现的元素、图内文字字体风格（没有就跳过）
3. 目标买家是谁（决定场景布置、模特选择、卖点）
4. 要几张、用在哪个平台（决定比例和裁切）

用户说“不用问了”时：默认生成一张影棚白底主图，用当前尺寸设置，并用一句话说明你的默认选择。

## 3. 选择画面类型

| 需求 | 类型 | 要点 |
|------|------|------|
| 平台主图、目录图 | 白底主图 | 纯白或极浅灰无缝背景，产品居中完整，柔和光，接触阴影，无道具无文字 |
| 突出一个卖点 | 卖点图 | 只讲一个卖点，用特写或剖面式构图；文案需要后期加时留出连贯的简洁区域 |
| 产品在真实使用环境 | 场景/生活方式图 | 场景与目标买家的生活相符；道具少而真实；用光或焦点让产品成为视觉中心 |
| 俯拍摆拍 | 平铺图 | 正上方垂直俯拍，单一侧光，所有阴影同向，全画面清晰 |
| 材质、做工 | 微距细节图 | 只拍一个特征，低角度掠射光，浅景深，指明最清晰的点 |
| 穿戴、手持、上脸 | 上身/手持图 | 人物只是展示手段，不能抢产品；手部自然；保留皮肤真实纹理 |
| 节日、大促 | 节日场景图 | 一个节日元素承载氛围，道具不遮挡产品 |
| 带标题、优惠、按钮 | 广告图 | 一个核心信息；标题逐字给出；文案不压住产品 |

有人物出镜按上身/手持图写；有图内文字按广告图写。各类型的提示词模板见 `references/formats.md`，需要时用 `read_skill_file` 读取。

## 4. 写提示词

每条提示词都放进产品图：`inputImageIds: [产品图 id]`，并在开头放这段**保真声明**（原样复用）：

```
图1 是真实产品。完全保留它的外形、轮廓、颜色、材质、Logo 和标签位置、可见结构细节和比例；
保持产品当前状态（盖着就保持盖着）。不要重新设计、增加、删除或移动产品的任何部件。只构建产品周围的场景。
```

然后只写参考图提供不了的东西：机位与构图、背景/场景、光线、阴影、镜头、氛围。

- **不要复述标签上的文字**：写出来会诱导模型重画，重画的字容易变形。
- **光线写位置和大小，不写灯具**：写“左上方大面积柔光”，不要写“柔光箱”，否则灯具会被画进画面。场景里本来就有的光源（窗户、台灯、蜡烛）可以写。
- **主动要求接触阴影**：产品和台面接触处的暗缝，没有它产品像是贴上去的。阴影方向与主光一致。
- **背景色根据产品选**：浅色产品配深一点的背景，深色产品配浅背景；说明是协调、互补还是对比。
- **不要编造卖点**：认证、参数、成分、销量、评分、徽章只用用户提供的，原文使用。
- **不写竞品或摄影师名字**，把想要的效果写成具体的光、色、构图。
- 结尾统一加：`商业产品摄影，杂志级画质，清晰锐利，材质真实，写实照片。避免：塑料感和统一油亮反光、变形或凭空出现的文字、融化或重影的结构、过度锐化和 HDR 光晕、正面闪光灯直打、库存图式摆拍、水印。`

## 5. 一组图怎么做

1. 先列出镜头清单（每张的类型、比例、要表达的点），**得到用户确认后再提交**，因为每张都要计费。
2. 统一的“观感块”（配色、台面、光线、机位高度）在每条提示词里一字不改地复用。
3. 每张都传同一张产品图。
4. 每张有自己要说的事，不要只换角度做近似图。
5. 多比例广告变体：同一创意按平台需要的比例分别提交，每个比例一个任务并填对应 `size`；不确定可用尺寸时不填 size，先问用户或用当前设置。文案和关键元素放在各比例都不会被裁掉的中心区域。

## 6. 提交与交付

- `create_image_task` 的张数严格按用户要求；不确定可用尺寸时不填 `size`；有小字或需要交付的成品可用 `quality: 'high'`。
- 不要为了“对比效果”多生成；结果有问题时如实指出哪里不对，问用户是否需要调整后再提交。
- 提醒用户：平台的具体图片规范、最终文案和宣传用语合规需要人工复核。

## 提交前检查

- [ ] 有真实产品图，且已放进 `inputImageIds`
- [ ] 保真声明在提示词开头，没有复述标签文字
- [ ] 没有编造卖点、参数、认证或评分
- [ ] 光线写位置和大小，有接触阴影
- [ ] 一组图已先得到用户确认，张数与要求一致
