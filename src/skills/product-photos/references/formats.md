# 产品图各类型模板

每条提示词都以正文第 4 节的“保真声明”开头，再接下面对应类型的场景部分，最后接统一的画质与“避免”行。场景部分**不描述产品本身**（颜色、材质、部件由参考图提供），控制在 150–250 字。

## 白底主图（影棚）

画面里只有产品和支撑它的东西，没有道具、手和环境。准确优先：形状、颜色、比例如实呈现。

```
机位与构图：<正面 / 三分之四侧 / 略低机位>，相机高度 <与产品中部齐平>，产品占画面约 <70%>，居中完整
背景：<纯白 / 暖中灰> 无缝背景纸，从产品后方一直延伸到下方，没有接缝和边角；亮度 <略高于 / 等于> 产品
光线：主光在镜头 <左上方>、高于产品，<大面积柔光>，色温 5500K；只在暗部或边缘需要时加一处 <右后方窄条轮廓光>
阴影：产品底部清晰的接触阴影，向 <右后方> 柔和延伸
镜头：<85mm> 等效焦段，小光圈，整件产品前后都清晰
色彩：中性白平衡，不受背景色污染
```

光线按材质选：高光泽表面用大面积柔光，有纹理的表面用小而硬的光。

## 卖点图

```
构图：聚焦 <用户提供的卖点，如“防滑纹理底座”>，<特写 / 剖面式裁切>
背景：简洁，不抢细节
留白：<画面右侧约三分之一> 为一块连续的 <浅灰渐变> 区域，色调统一，便于后期放文案
约束：不编造参数、认证或材料；不渲染小字说明
```

不要单纯要求“留空白”，空白容易变成一块没有质感的色块；写成“连续、有轻微纹理的浅色区域”。

## 场景 / 生活方式图

卖的是“拥有它之后的生活”，场景要与目标买家的生活相符，既不过分奢华，也不寒酸。

```
机位与构图：<略高于台面的平视>，产品在 <画面左下三分点>，占画面约 <30%>
场景：<清晨的小户型厨房台面>，前景 <虚化的木砧板一角>，背景 <窗边绿植>，有纵深
道具：<两三件> 这个买家本来就会有的物品，带一点使用痕迹（<桌上的水渍、几粒咖啡豆>）
动作：<一只手伸向产品，但未触碰> / 无人物
焦点：<一束窗光只落在产品上>，让它成为视觉中心
光线：<早晨 8 点> 从 <左侧窗户> 照入的自然光，色温约 5000K，产品与环境同一色温
镜头：<50mm>，<f/2.8>，产品清晰，背景柔和虚化
氛围：<安静、从容的早晨>
```

## 平铺图

```
机位：正上方垂直俯拍，镜头与台面平行，距离足够远，边缘物品与中心一样不变形
台面：<浅色亚麻布 / 水磨石>，同时充当背景
构图：产品放在三分点上，是画面里最大或最亮的物体；保留三分之一到三分之二的连续台面
道具：<3 / 5> 件同一主人会有的物品，沿对角线分组；可以互相交叠，但不压住产品
光线：只有一个方向光，从 <左上方> 斜射，色温 <4500K>
阴影：所有阴影同向、长度一致、边缘柔和
镜头：全画面从前到后都清晰
```

## 微距细节图

```
取景：极近特写，只拍 <瓶盖的金属拉丝边缘>，占画面约 <60%>，裁切线穿过 <瓶身上部>
背景：<深灰>，大幅虚化
光线：一盏主光以接近平行于表面的低角度从 <左侧> 掠射，<硬光、光源较小>，色温 5500K
镜头：微距镜头，<f/4>，最清晰的点在 <边缘的高光线>，其余逐渐虚化
```

一张只表现一个属性；同时要纹理和光泽，两者都出不来。

## 上身 / 手持图

人物只是展示产品的手段，一切服从于“产品看得清”。

```
景别与构图：<半身>，裁切落在关节之间（不切在手腕、膝盖上），产品约占画面 <25%>
模特：<女性，约 30 岁，中等身材，黑色齐肩短发，自然肤色>，贴近目标买家而非时尚大片模特；一组图里每条都写完整
穿搭：产品的穿着状态（<拉链拉上 / 敞开>），其他衣物 <素色基础款>，不抢产品
姿势与动作：一个进行中的动作（<低头整理袖口>），重心、视线、双手各自在做什么写清楚
场景：<浅灰墙面>，简单不抢戏
光线：皮肤需要大面积柔光，硬质产品需要小而硬的光，说明以哪个为主光；方向 <左前方>，色温 5000K；保留真实皮肤纹理
镜头：<85mm>，<f/2.8>，产品和脸都清晰
避免：手和脸变形、多指少指、磨皮过度、眼神空洞、不自然的肢体姿势
```

## 节日场景图

```
节日元素：只用一个承载节日氛围的元素（<一枝挂着红色果实的冬青>），配色来自这个节日
道具：看起来像是本来就放在那里的，不遮挡产品
其余按场景图写
```

## 广告图（带文案）

先确定一个核心信息：消费者真实的痛点或期待 + 产品的一个事实，合成一句话的创意。一组广告每张基于不同的洞察，而不是同一洞察换个画法。

```
用途：<信息流广告 / 电商横幅>
创意：<一句话描述这张广告讲什么>
画面：<产品在构图中的位置>，单一视觉焦点，主体与背景明显分离
标题（逐字）：“<用户提供的标题>”，<粗体无衬线，白色>，位于 <画面上部>，只出现一次
辅助文案（可选）：“<用户提供的说明>”，字号明显小于标题
行动按钮（可选）：<填充色块> 内写 “<立即购买>”，使用点缀色
配色：<主色、辅色、点缀色>
约束：文案不压住产品；只出现以上文字；不添加评分、徽章、统计数字；无水印
```

多比例变体：方图 1:1、竖版 4:5 或 9:16、横版 16:9 等按平台需要分别提交；标题和产品放在中心安全区，避开平台自带按钮和头像通常所在的边缘位置。
