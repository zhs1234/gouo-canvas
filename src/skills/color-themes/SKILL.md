# 配色主题

## 1. 选主题

1. 用户已给出颜色（品牌色、hex 值、“蓝白配”）→ 直接用，必要时补一个中性色。
2. 用户只给了感觉（“温暖”“高级”“科技感”）→ 从 `references/themes.md` 中挑 2–3 套最合适的，用一句话介绍各自的氛围，让用户选。需要时用 `read_skill_file` 读取。
3. 都不合适 → 根据用户描述定制一套：起一个描述性的中文名，给出 4 个颜色（深色锚点、主色、辅色、浅色背景）和适用场景，先给用户确认。

不要在用户没要求配色时擅自给每张图套主题。

## 2. 写进提示词

把颜色**绑定到具体对象**上，只写“用蓝色和橙色”时颜色会随意落到最近的物体上：

```
配色：
- 背景：深海军蓝 #1a2332
- 主体与主要图形：青绿色 #2d8b8b
- 次要元素与高光：海沫浅蓝 #a8dadc
- 文字：奶白 #f1faee
- 整体：低饱和、冷色调，高对比的文字与背景
```

要点：

- 2–3 个主导色 + 1 个点缀色就够，说明它们是协调、互补还是对比关系。
- hex 值配上颜色名称一起写，模型对名称和氛围描述的响应比单纯 hex 更稳定；hex 用来提醒精确倾向，不保证像素级一致。
- 写清面积比例，如“背景占约 60%，主色 30%，点缀色 10%”。
- 摄影类画面把配色落到场景物体上（“墙面是砂色，桌布是陶土红”），而不是给照片加滤镜。
- 产品图里**不要改变产品本身的颜色**，配色只用于背景、道具和光线氛围。
- 图内文字与背景保持足够对比，浅底配深字、深底配浅字。

## 3. 一组图保持统一

- 把配色块原样复用到这一组的每条提示词里，不要换说法。
- 同时固定光线色温和质感描述（如“柔和的暖色侧光，哑光纸张质感”），色调才真正统一。
- 有品牌套件时，以品牌色为准，主题只作补充。

## 4. 提交

- 配色不影响张数和尺寸：张数按用户要求，不确定可用尺寸时不填 `size`。
- 用户想比较多套配色时，先说明每套会单独计费，确认后每套一个任务。

## 提交前检查

- [ ] 每个颜色都绑定到具体对象或区域
- [ ] 主导色不超过 3 个，有明确的点缀色
- [ ] 产品本身的颜色没有被改写
- [ ] 文字与背景对比足够
- [ ] 一组图使用同一配色块
