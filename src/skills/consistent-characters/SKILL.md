# 角色与主体一致性

每次生成都是独立的，一致性要靠三样东西共同维持：**定稿参考图**、**一字不改的固定描述块**、**明确的“可变/不可变”清单**。只说“同一个角色”是不够的。

## 1. 先做定稿图

开始系列之前，先生成一张**角色设定图**（或产品定稿图），让用户确认：

```
用途：角色设定图
主体：<角色描述>
风格/媒介：<绘本水彩 / 3D 卡通 / 写实>
构图/取景：全身正面站姿，<可选：同一画面并排展示正面、侧面、背面三视图>
背景：纯色简洁背景，清楚展示角色
约束：原创角色，不模仿已有版权角色；无文字；无水印
```

- 设定图越干净（纯背景、全身、无遮挡），作为参考越可靠。
- 用户确认后，记下这张图的 id，后续每张都放进 `inputImageIds`。
- 用户已经有角色图时，直接用它当定稿图。

## 2. 写固定描述块

从定稿图提炼一段描述，之后**每条提示词原样粘贴**，不要换说法——换个说法模型会当成新指令。

```
角色固定特征（每张保持完全一致）：
- 轮廓与比例：<头身比 1:3，圆脸，略大的头>
- 面部：<圆眼、短眉、雀斑在鼻梁两侧>
- 发型与颜色：<栗色短卷发，右侧别一枚黄色发夹>
- 服装：<绿色连帽短袍，棕色软靴，腰间小皮包>
- 标志性物件：<背着一把小木弓>
- 配色：<森林绿、栗棕、奶白>
```

再写两张清单：

- **可以变化**：场景、天气、时间、动作、表情、机位远近
- **不要引入**：新配饰、换发色、改服装款式、额外角色（除非剧情需要）

产品系列同理：锁定瓶型、标签比例、瓶盖材质、品牌色；允许变化背景、光线氛围、道具点缀、机位高度的小范围变化。

## 3. 继续生成新画面

```
输入图片：图1 是角色定稿图
主要需求：继续绘本故事，同一个角色在 <暴风雪后的森林里，跪在倒下的树旁，安慰一只受惊的松鼠>
<粘贴角色固定特征块>
可以变化：场景、动作、表情
约束：不要重新设计角色；保持与图1 相同的面部、比例、服装和配色；同样的画风；无文字；无水印
```

- 定稿图始终作为图1；需要额外参考（场景、道具）时排在后面，并写明各自只控制什么，避免风格参考覆盖角色身份。
- 也可以把上一张满意的结果作为补充参考（`get_task_status` 取输出图片 id），但定稿图优先，防止误差一张张累积。
- **每次只改一个变量**：先换场景，满意后再换动作或天气。同时改太多，角色最容易走样。
- 保持相同的画面比例，除非平台要求不同；机位变化不要大到让角色像换了一个人；光线不要剧烈到让材质看起来变了。

## 4. 多格漫画与分镜

- 一张图内多格：写“<4> 个等大格子”，逐格写一个具体动作，固定描述块放在最前面统一适用于所有格子。
- 跨多张图的分镜：先列出镜头表（每张的场景、动作、景别），得到用户确认再提交，因为每张都单独计费。
- 不需要的话写“无文字”；需要对白时逐字给出，每格一句以内。

## 5. 漂移了怎么办

- 指出具体漂移点，把它加进锁定项再试一次（“恢复右侧黄色发夹”），而不是重写整段。
- 连续漂移时，回到定稿图重新出发，不要以漂移后的图为参考。
- 先把结果交给用户，问是否需要修正，不要自行反复提交。

## 6. 真实人物

使用真实人物照片做系列时，只处理用户本人或已获授权的人物；不生成冒充、误导或有损名誉的内容。

## 提交前检查

- [ ] 有经过用户确认的定稿图，且它是 `inputImageIds` 里的图1
- [ ] 固定描述块与上一张一字不差
- [ ] 写了“可以变化”和“不要引入”
- [ ] 这一张只改了一个主要变量
- [ ] 比例、画风与前面保持一致；张数与用户要求一致
