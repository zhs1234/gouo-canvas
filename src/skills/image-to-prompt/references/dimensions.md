# 观察维度清单

仅供内部使用，不要把逐项结论展示给用户。按图的实际类型挑选相关部分。

## 通用维度

1. **构图**：画幅比例和方向；主体位置与占比；前中后景与留白；居中、三分、对称、对角、框景、散点；水平、垂直、对角、三角、S 形、环形、放射等结构线；视觉中心和视线路径；主次、遮挡、重复、平衡。
2. **机位与透视**：平视、俯拍、仰拍、顶拍、航拍；特写、半身、中景、全身、远景；广角感、自然透视、长焦压缩；近大远小；前景遮挡和框景（玻璃、窗、门洞、树叶）；对焦位置；倾斜或动感机位。
3. **光线**：主光方向；硬光、柔光、逆光、侧光、顶光、环境光；自然光、影棚光、窗光、霓虹、体积光；轮廓光、反光、补光、局部高光和阴影位置；光晕、光斑；整体色温和明暗比；光如何塑造体积、材质和氛围。
4. **色彩**：主色、辅色、点缀色；冷暖倾向；饱和度、明度、对比；单色、互补、邻近、冷暖对比；霓虹、高级灰、粉彩、复古、胶片、商业通透。色彩如何引导视线、分离主体、营造氛围。
5. **材质**：皮肤、毛发、羽毛、布料、皮革、纸、金属、玻璃、塑料、树脂、陶瓷、木、石、水、冰、雾、烟、植物、屏幕、包装、食物表面。反射、粗糙度、湿润度、透明或半透明、哑光、软硬、纹理、划痕、褶皱、油光、霜、粉感。找出最重要的材质记忆点。
6. **景深与空间层次**：背景清晰还是不同程度虚化；前景虚化；主体与背景分离；焦外光斑、雾气、渐变阴影、树影、倒影；背景几何（线条、网格、光斑、大色块、山峦层次、建筑轮廓、街道透视线）；背景是讲故事还是只做氛围。
7. **内容与氛围**：主体外观、形状、大小、颜色、朝向和状态；辅助元素、道具、环境物的位置；室内外、地点类型、时间、季节、天气；主体的动作及与道具、背景的关系；整体情绪及其具体视觉来源。
8. **后期与画质**：颗粒、噪点、柔焦、动态模糊、胶片感、色差、锐化、镜头光晕；商业修图、电影调色、CG 渲染后期、产品精修、皮肤修饰；清晰度和细节密度。

## 分类型要点

- **人物与人像**：可见的年龄感和性别呈现、脸型、五官、发型、妆容、表情、视线、头部角度、身体朝向、姿势、手脚位置、重心、离镜头最近的部位、服饰配件、皮肤质感、人物与环境的关系。无法可靠判断身份、年龄、族裔时只描述可见外观。
- **摄影**：光的类型；景深与对焦；广角、自然、长焦效果；冷暖、复古、商业、胶片倾向；纪实、影棚、随手拍、时尚人像、电影剧照等类型。证据不足时不写具体相机参数。
- **产品与商业摄影**：品类、形状、颜色、朝向、占比、包装结构、边缘、按钮、接口、标签位置、表面材质、高光、粗糙度、透明度、阴影位置；水珠、粉末、液体、蒸汽、冰块、花瓣等道具；背景布置；哪些可见结构和材质在传达卖点。不生成清晰品牌标志、乱码包装文字或不存在的功能结构。
- **字体、Logo 与文字设计**：现代、复古、赛博、手写、极简、装饰风格；字形宽窄、倾斜、圆润度、几何感、比例；笔画粗细、衬线结构、切角、连笔、断笔和负空间；字距、行距、层级；描边、发光、渐变、浮雕、阴影、立体效果；金属、哑光、玻璃、霓虹、纸张材质。
- **自然风景与城市**：环境类型、季节、天气、晨昏昼夜蓝调；地平线与层次；天空、云、水、雾和空气透视；植被、山、建筑、街道、灯光、倒影。不要凭模糊的视觉效果编造具体地点或地标。
- **建筑与室内**：空间类型和功能、透视方向、灭点、主线条、前中后景、建筑/家具/墙地面材质、自然光/窗光/灯带、空间尺度、秩序感，窗外景色。
- **3D 渲染**：写实、半写实、3D 卡通、黏土、玩具、极简；建模比例、圆角、细节精度；哑光、金属、玻璃、亚克力、树脂、陶瓷材质；反射、折射、次表面散射；三点光、柔光、轮廓光、体积光；接触阴影、后期辉光。
- **IP 角色、Q 版、潮玩盲盒**：头身比、体型、轮廓、五官、表情、发型、服饰、配饰、动作、材质、柔光、纯色背景、展示台、全身设计。只描述视觉特征，不依赖具体 IP 名称。
- **动物**：种类、体型、毛色、姿势、动作、视线、毛发/羽毛/鳞片质感、与环境的关系。无法可靠识别品种时只描述可见特征。
- **食物**：种类、主要食材、形状、颜色、摆盘、占比、油光、酱汁、蒸汽、酥脆、湿润、奶油、糖霜、拉丝、滴落、餐具、桌面材质，以及哪些颜色、光泽、质感带来食欲。
- **交通工具**：类型、角度、车身材质、反射、车灯、高光线、静止或运动、环境、速度线、扬尘、水花、动态模糊。默认排除清晰的品牌标志、车牌和可读文字。
- **植物与花卉**：形态、颜色、数量、生长状态、花瓣/叶片/花粉/露珠纹理、透光、前景遮挡和虚化。
- **平面海报与视觉设计**：版式结构、主视觉位置、色块、图形元素、留白、网格、对齐、视线流、层级、文字区的位置和层级、颗粒、渐变、描边、拼贴、故障效果。要复刻版式而非文字内容时写“预留文字区”。
- **抽象图形与多主体**：基本几何、曲线、色块、纹理、重复、主次、节奏、平衡、方向、透明叠加、发光、渐变；多主体之间的距离、遮挡、比例和叙事关系。

## 插画风格

主媒介是插画时，把“画了什么”和“怎么画的”分开：

- **风格指纹**：媒介与渲染方式（线稿、平涂、赛璐璐、厚涂、水彩、水粉、水墨、铅笔、炭笔、版画、拼贴、剪纸、矢量、像素）；线条语言（无描边、细描边、粗描边、粗细变化、断线、草稿线、毛笔线）；造型语言（写实、简化、几何、圆润、拉长、Q 版、夸张）；明暗语言（平涂、硬边色阶、柔和过渡、水彩晕染、干笔、强明暗对比）；色彩语言（有限色板、互补、低饱和、粉彩、高饱和、大地色、霓虹点缀）；纹理与细节分布（干净数码表面、纸纹、笔触、网点、颜料颗粒、主体细节密而背景简）。
- **证据权重**：全画面反复出现的特征 > 影响主体轮廓的特征 > 表面质感 > 局部装饰。不要把单个小笔触或压缩噪点当成风格。
- **主次风格**：只选一个主风格方向，最多两个辅助技法。冲突时保留证据更强、覆盖更广的一方，例如不要同时写“扁平矢量”和“厚重油画堆叠”、“无描边”和“粗黑闭合轮廓”。
- **篇幅比例**（插画提示词）：约 35–45% 写风格指纹和风格锚点，20–30% 写主体外观动作服饰，15–20% 写构图、视角、光线和层次，其余写背景、叙事、氛围和媒介边界。
