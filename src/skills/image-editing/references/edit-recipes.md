# 编辑模板

按需复制后替换尖括号里的内容。图1、图2 的顺序与 `inputImageIds` 一致。

## 删除物体

```
输入图片：图1 是原图
主要需求：去掉男人手里的花
约束：其他一切保持不变，包括人物的脸、姿势、衣服、背景和光线；被遮挡的手部自然补全
```

## 替换物体

```
输入图片：图1 是房间照片
主要需求：只把 <白色椅子> 换成 <原木椅子>
约束：保持机位角度、室内光线、地面阴影和周围物品；其他方面完全不变
细节：真实的接触阴影和材质纹理
```

## 添加物体

```
输入图片：图1 是原图
主要需求：在 <桌面右侧> 放一个 <白色陶瓷咖啡杯>
约束：杯子的大小、透视和光照方向与桌面一致，有接触阴影；其余内容保持不变
```

## 换背景

```
输入图片：图1 是产品照
主要需求：只把背景换成 <温暖的日落渐变>
约束：保持产品及其边缘、轮廓、标签、裁切和机位完全不变；产品上只允许出现新背景带来的轻微环境反光；不加文字，不加水印
```

## 白底抠图准备

```
输入图片：图1 是产品照
主要需求：把产品放到纯白背景上，居中
约束：轮廓清晰，没有光晕或毛边；标签文字保持原样；不改变产品造型和颜色；不加阴影以外的任何元素
```

## 换装（人物保真）

```
输入图片：图1 是人物全身照；图2 到图4 是服装参考
主要需求：只把图1 人物的衣服换成图2 到图4 的服装
约束：不改变脸、五官、肤色、体型、姿势、发型、表情和身份；服装贴合现有姿势，有真实的垂坠和褶皱；光线、阴影和色温与原图一致；背景、机位、取景不变；不加配饰、文字或标志
```

## 人物放进新场景

```
输入图片：图1 是人物照片
主要需求：把这个人放进 <黄昏的露营地> 场景，<她正在收帐篷>
约束：保持人物的脸、五官和体型；看起来像真实拍到的照片，自然光，真实色彩
避免：电影海报感、夸张调色、风格化构图
```

## 光线与天气

```
输入图片：图1 是原图
主要需求：变成 <下着小雪的冬日傍晚>
约束：保持主体身份、几何结构、机位和构图；只改变光线、阴影、大气和天气；地面有相应的积雪或湿润
```

## 局部改色

```
输入图片：图1 是原图
主要需求：只把 <帽子> 的颜色改成 <深绿色>
约束：保持帽子的形状、材质和褶皱；不改变饱和度、对比度和画面其他部分
```

## 风格迁移

```
输入图片：图1 是风格参考
主要需求：用图1 的视觉风格画 <一个骑摩托车的男人，纯白背景>
约束：保留图1 的配色、纹理和笔触；不添加多余元素
```

## 多图合成

```
输入图片：图1 是底图场景；图2 里有要插入的狗
主要需求：把图2 的狗放到图1 中女人的右边
约束：匹配图1 的光线方向、透视、比例和阴影；图1 的构图、背景和人物保持不变；不添加其他元素
```

## 草图转渲染

```
输入图片：图1 是手绘草图
主要需求：把草图变成写实照片
约束：严格保持布局、比例和透视；选择与草图意图一致的真实材质和光线；不新增元素或文字
```

## 文字替换（保留版式）

```
输入图片：图1 是原海报
主要需求：把 “<原文字>” 换成 “<新文字>”
约束：只改文字；保持字体风格、字号、颜色、位置和层级；不改动图像、标志和其他文字
```
