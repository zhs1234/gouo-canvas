# 参考图编辑与局部修改

编辑 = 把图片 id 放进 `create_image_task` 的 `inputImageIds`，在 `prompt` 里写清“改什么、保留什么”。模型会重新生成整张图，所以**没写明要保留的东西都可能漂移**。

## 1. 准备输入图

1. 确定要改的那张图的 id：用户附件看系统提示里的参考图片 ID，本会话生成的图看 `get_task_status` 返回的 outputImageIds，画布上的图用 `get_canvas()` 查找；用户指代不明（“这张”“刚才那张”）且画布上有多张候选时，先确认。
2. 上一轮的生成结果可以继续当输入：用 `get_task_status({ taskId })` 拿到输出图片 id，再放进 `inputImageIds`。
3. 不是每张输入图都是“被改的对象”。逐张标明角色，按 `inputImageIds` 的顺序称为图1、图2……

```
输入图片：图1 是要修改的原图；图2 是服装参考；图3 是光线氛围参考
```

常见角色：**编辑对象**（在它上面改）、**主体/身份**（人脸、产品外形）、**风格**（色彩、笔触、质感）、**材质**、**版式**（构图、留白、标题区）、**插入素材**（要放进画面的物体或人）。

写清每张图**控制什么、不控制什么**，例如“只用图2 的外套款式和面料，不要改变图1 人物的脸和姿势”。参考图之间冲突时，以用户指定的主图为准。

## 2. 编辑提示词公式

按这个顺序写，越靠前越重要：

1. **锁定项**：先列必须保持不变的内容
2. **改动范围**：只改哪个区域或哪个属性
3. **新状态**：改成什么样（材质、颜色、形状、光线）
4. **防波及**：相邻的哪些东西不能被带着改动

```
用途：局部替换
输入图片：图1 是厨房照片
主要需求：只把白色椅子换成原木椅子
约束：保持机位角度、室内光线、地面阴影和周围物品不变；其他一切保持原样
细节：椅子与地面有真实的接触阴影，木纹自然
```

锁定项优先级（按需挑选，不必全写）：身份/主体外形 → 裁切与机位 → 姿势与轮廓 → 材质 → 标志、标签、文字 → 阴影与倒影 → 环境布局。

用确定的词：“保持不变”“完全一致”“不要改变”。不要写“大致保持”“差不多”。

## 3. 各类编辑要点

| 类型 | 要点 |
|------|------|
| 加/删/换物体 | 指明具体对象和位置；保持周围纹理和光线；“其他一切不变” |
| 换背景 | 锁定主体、边缘、裁切、机位；只换背景；处理好主体上的环境反光 |
| 人物保真（换装、换场景） | 锁定脸、五官、肤色、体型、姿势、发型、表情；只改指定部分；衣物贴合身体有自然褶皱；光影与原图一致 |
| 光线与天气 | 只改光的方向/软硬、阴影、大气、降水、地面湿润；保持几何、构图、主体身份 |
| 风格迁移 | 说清要保留的风格线索（配色、纹理、笔触、颗粒），以及要换成的新内容；加“不要添加多余元素” |
| 多图合成 | 写明把哪张图的什么放到哪张图的哪里；匹配光线、透视、比例和阴影；保持底图构图不变 |
| 草图转渲染 | 保持布局、比例、透视；为草图选合理的材质和光线；不新增元素和文字 |

各类型的完整模板见 `references/edit-recipes.md`，需要时用 `read_skill_file` 读取。

## 4. 能力边界，要如实告诉用户

- 这里没有遮罩参数，无法做到像素级精确的局部重绘。需要严格只改某一小块时，建议用户到创作页使用“遮罩”功能，自己涂选区域后再编辑。
- 没有透明背景参数。需要抠图时，改为“纯白背景、主体完整、边缘清晰、无光晕”，并说明需后期抠图。
- 一次改动太多（同时改身份、姿势、背景、光线、服装、文字），就不再是编辑，建议直接重新生成。
- 涉及真实可识别人物时，只处理用户本人或已获授权的照片；不做冒充、误导性或侮辱性的修改。

## 5. 迭代

- 每次只改一处，并在每一轮**重复完整的锁定项**，不要只写“同上”。
- 出现漂移时，把漂移的部分加进锁定项（“恢复原来的发型”），而不是重写整段提示词。
- 结果不满意先问用户哪里不对，不要自行重复提交。

## 提交前检查

- [ ] `inputImageIds` 里的图和用户指的图一致，顺序与提示词里的图1、图2 对应
- [ ] 每张输入图的角色写清楚了
- [ ] 先写锁定项，再写唯一的改动，再写防波及
- [ ] 没有顺手加入用户没要求的改动
- [ ] 需要像素级精确时，已提示用户可用创作页的“遮罩”
