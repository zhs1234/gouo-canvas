# 分用途示例提示词

这些是写完整的示例，用来参考结构和用词，不代表每个请求都要补到这么多细节。改写时保留用户原有要求，只按“补充多少细节”的原则增减。

## 自然写实照片

```
用途：自然写实照片
主要需求：一位老水手在小渔船上整理渔网的抓拍照片
场景/背景：海面带薄雾的近岸
主体：饱经风霜的皮肤，皱纹和日晒痕迹清晰
风格/媒介：写实抓拍照片，胶片质感
构图/取景：中近景，平视
光线/氛围：柔和的海边日光，浅景深，轻微胶片颗粒
材质/纹理：真实皮肤纹理、磨旧的衣物、被海水浸蚀的木头
约束：自然色彩平衡，不做重度修图，不美化
避免：影棚感、摆拍感、水印
```

## 产品与包装

```
用途：产品图
主要需求：哑光黑色洗发水瓶的高端产品照，标签极简
场景/背景：浅灰到白色的干净影棚渐变
主体：单瓶居中，带轻微倒影
风格/媒介：高端产品摄影
构图/取景：居中，略带三分之四侧角，四周留足空间
光线/氛围：大面积柔光，高光干净，阴影受控，底部有接触阴影
材质/纹理：哑光塑料，标签印刷清晰
约束：无真实品牌标志，无水印
```

## 信息图与图解

```
用途：信息图
主要需求：全自动咖啡机工作流程的详细图解
场景/背景：干净的浅色中性背景
主体：豆仓 → 磨豆器 → 冲煮单元 → 锅炉 → 水箱 → 接水盘
风格/媒介：干净的矢量风信息图，带标注线和箭头
构图/取景：竖版海报，自上而下的流程
图内文字（逐字）：“豆仓”“磨豆器”“冲煮单元”“锅炉”“水箱”“接水盘”
约束：标签清晰，对比强，无品牌标志，无水印
```

提示：信息密集或小字多时，`quality` 用 `high`。

## 幻灯片与图表

```
用途：演示页
资产类型：16:9 汇报幻灯片一页
主要需求：展示市场规模的柱状图
主体：标题“三年市场规模”；三根柱子分别标注“2024：12 亿”“2025：18 亿”“2026：27 亿”
风格/媒介：简洁商务风，扁平图形，留白充足
约束：只出现给定文字和数字；字号清晰可读；不用库存照片，不加装饰杂物
```

提示：把真实数据和标签直接写进提示词；横版尺寸；`quality` 用 `high`。

## Logo 与标志

```
用途：Logo
主要需求：为本地面包店“麦田与面粉”设计原创标志
风格/媒介：矢量感标志，扁平色，极简
构图/取景：单个标志居中，纯色背景，四周留白充足
约束：轮廓强，负空间平衡，小尺寸也能识别；原创设计；非必要不用渐变；不模仿任何已有商标；无水印
```

## 插画与故事（分格漫画）

```
用途：分格漫画
主要需求：4 格竖版漫画，讲宠物独自在家
风格/媒介：漫画插画，分格清晰
构图/取景：4 个等大的格子
主体：
第 1 格：主人出门，宠物在窗后睁大眼睛，爪子贴着玻璃
第 2 格：门关上，宠物慢慢转身看向空荡的屋子
第 3 格：宠物摊在沙发上像主人一样，阳光像聚光灯一样照进来
第 4 格：门打开，宠物端坐在门口，一副什么都没发生的样子
约束：无文字，无水印
```
