# 图内文字与多语言化

把图里的文字当作**排版系统**来写：逐字内容、层级、位置、边距、背后是否干净。只写“在某处加上文字”几乎一定出错。

## 1. 先确认文字内容

- 文字必须来自用户，逐字确认，包括标点、大小写、数字格式。用户只给了大意时，先拟好文案给用户确认，不要直接提交。
- 用户没提到文字时，**不要主动加文字**；需要时写“无文字”。
- 文字越短越准：每段尽量不超过 10 个汉字或 25 个英文字母，全图 1–3 段为宜。大段正文、价格表、法律声明建议后期排版。

## 2. 写法

```
图内文字（逐字，不要添加其他文字）：
- 标题：“<文字>”，<粗体无衬线 / 书法感毛笔字 / 细衬线>，<白色>，位于 <画面上部三分之一居中>，字号最大
- 副标题：“<文字>”，<常规粗细>，位于标题下方，字号约为标题的一半
- 按钮：<深色圆角色块> 内写 “<文字>”
排版：四周留出约 8% 的安全边距；文字背后的区域保持简洁、低细节；每段文字只出现一次
```

要点：

- 用引号包住逐字内容，并写明“只出现一次，不加其他字符”。
- 描述字体的特征（粗细、衬线、手写、圆润、几何感），不要写具体字体商标名。
- 写清层级：标题、副标题、正文、按钮、标签的大小关系。
- 不要把小字放在复杂纹理、高细节背景上；需要时写“标题背后是简化的天空/纯色区域”。
- 生僻词、品牌拼写、外文：逐个字母拆开写，例如 “B-R-I-O-C-H-E”。
- 小字、密集标注、多种字体时，`quality` 用 `high`。

## 3. 中文文字技巧

- 中文标题优先短词组（2–8 字），笔画多的字放大字号。
- 写明字形风格：“方正粗黑的现代黑体”“圆润的手写体”“宋体式的细衬线”“毛笔书法，飞白明显”。
- 竖排时明确写“竖排，从右到左”或“竖排单列”。
- 中英混排时分别写清两种文字的位置和大小，避免模型把中文改成英文或拼音。
- 生僻字、易混字（如“己/已”“末/未”）可以额外注明“注意是‘已经’的‘已’”。
- 要求“简体中文”或“繁体中文”，不要让模型自行决定。

## 4. 翻译与本地化已有图片

把原图 id 放进 `inputImageIds`：

```
输入图片：图1 是原始 <信息图 / 海报 / 包装 / 界面截图>
主要需求：把图中文字翻译成 <英文>，逐条替换：
“豆仓” → “Bean Hopper”
“磨豆器” → “Grinder”
“锅炉” → “Boiler”
约束：只改文字；保持字体风格、字号、颜色、位置、间距和层级；不改动图像、图标、标志和布局；不增加任何额外文字
```

- 最好先列出原文与译文对照，请用户确认译文后再提交。看不清原图文字时请用户提供原文。
- 译文明显比原文长时，提示用户可能需要缩短译文或允许轻微调整字号，而不是让版面重排。
- 品牌名、产品型号通常不翻译，写明“保持原样”。
- 多语言版本：每种语言一个任务，使用同一套约束。

## 5. 修正写错的字

- 用上一版结果作为输入图，只针对错误的那段：`把 “<错字版本>” 改为 “<正确文字>”，其他一切保持不变`。
- 仍然出错时：简化文字背后的画面、缩短文案、拉大层级对比、提高 `quality`。
- 多次尝试仍不准，建议用户在创作页用“遮罩”只选中文字区域重绘，或后期在设计软件里排字。
- 先告诉用户问题所在，再决定是否重新提交，不要自行反复重跑。

## 提交前检查

- [ ] 所有文字逐字来自用户或已经用户确认
- [ ] 每段文字都有字体风格、位置、大小层级
- [ ] 写明“只出现一次，不添加其他文字”
- [ ] 文字背后的区域足够简洁，留有安全边距
- [ ] 翻译时只改文字，版式和图像的其他部分锁定
