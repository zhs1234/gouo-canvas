# 海报与艺术设计

分两步：先确立**设计理念**（一种审美取向），再把理念**用画面表达出来**。成品 90% 是视觉设计，10% 是必要文字。

## 1. 收集必要信息

需求不清楚时先问，最多 3 个问题：

- 用途和场合（展览、演出、产品发布、节日、书封……）
- 必须出现的文字（标题、日期、地点），逐字确认
- 方向偏好（克制/热烈、几何/有机、摄影/插画），没有就由你提案

用户只给了一个主题（如“爵士音乐节”），不必追问细节，直接进入第 2 步。

## 2. 写设计理念

给这个理念起一个 2–4 字的名字，再用 4–6 句话说清它如何通过以下方面表现，每个方面只说一次，不重复：

- **空间与形态**：大面积色块还是细密排布，几何还是有机
- **色彩与材质**：有限色板（2–4 色），纸纹、颗粒、油墨、金属等质感
- **尺度与节奏**：大与小的对比，重复与变化
- **构图与平衡**：网格、对称、对角线张力、大面积留白
- **视觉层级**：视线先落在哪里，文字处于什么位置
- **文字的角色**：耳语般的小标签，还是粗犷的大字；永远少而精

理念要具体到能指导画面，又留出发挥空间。强调成品要像经过反复推敲、由顶尖设计师精心完成的作品，而不是随手的装饰画。

理念示例（只作参考，要为每个需求原创）：

- **「混凝土诗」**：巨大的色块、雕塑般的字形（一个巨大的单词配极小的标签）、粗野主义的空间分割。靠视觉重量和空间张力说话，文字是少而有力的姿态。
- **「色彩语言」**：色彩本身就是信息系统。精确的几何色区，小号无衬线标签只用来锚定色彩已经表达的内容。
- **「模拟冥想」**：纸张纹理、油墨晕染、大片留白，图像在画面中呼吸，文字轻声细语。
- **「有机系统」**：圆润形态、模块化生长和自然聚集，信息通过图形关系和空间位置呈现。
- **「几何静默」**：严格的网格秩序、大胆的图形或摄影、戏剧性的负空间，结构本身就是表达。

## 3. 找到隐含的主题线索

把用户的主题**含蓄地**织进形态、色彩和构图里，而不是直白地画出来。懂的人一看就能感到，不懂的人也能欣赏一幅出色的构图。例如“爵士音乐节”可以表现为切分节奏般错落的色块，而不是画一把萨克斯。

用户明确要具象内容（人物、产品、场景）时，以用户需求为准，理念只决定画法。

## 4. 转成提示词

把理念翻译成可见的画面指令，用分栏写：

```
用途：<展览海报 / 活动主视觉 / 书籍封面>
设计理念：<名字>——<一句话核心>
主视觉：<画面的主体形态和它在画面中的位置>
构图：<网格 / 对称 / 对角线；视觉焦点位置；留白占比>
色彩：<2–4 个颜色，说明主次和对比方式>
质感：<纸纹、丝网印刷颗粒、哑光、细噪点等>
图内文字（逐字）：“<标题>”，<字体风格、粗细、大小、位置>；“<副信息>”，<更小，位置>
约束：所有文字和图形在画面边界内，留出边距，互不重叠；只出现以上文字；原创设计
避免：杂乱装饰、廉价模板感、卡通化、水印
```

- 文字越少越好。标题一个，副信息一两行；大段文字交给后期排版。
- 需要具体配色时可以使用配色主题，在“色彩”行写明 hex 值和用途。
- 海报通常是竖版；不确定可用尺寸时不填 `size`，按用户当前设置。
- 小字较多时 `quality` 用 `high`。

## 5. 原创与版权

- 不模仿在世艺术家或设计师的标志性风格，不写“×× 风格”加人名；需要时描述具体技法（如“丝网印刷的错版套色”“瑞士网格排版”）。
- 不复制受版权保护的作品、电影海报、角色形象或商标。
- 用户点名要模仿某位在世艺术家时，说明原因并提供基于通用技法的原创方案。

## 6. 提交与迭代

- 先用一两句话把设计理念和画面方案告诉用户，再提交。用户已说“直接做”时可以直接提交。
- 张数按用户要求。要多个方向时，建议每个方向一个任务，各自用不同理念。
- 修改时**精炼而非堆砌**：优先让现有构图更统一、更干净，而不是再加新图形和滤镜。
- 系列海报：保持同一理念、网格和字体风格，每张用独特的变化推进，像一本画册里的不同页。

## 提交前检查

- [ ] 设计理念有名字，覆盖构图、色彩、留白和文字角色
- [ ] 视觉为主，文字极少，且逐字放在引号里
- [ ] 主题以含蓄方式融入画面（除非用户要具象内容）
- [ ] 没有在世艺术家名字、版权作品或真实商标
- [ ] 写明文字和图形不出界、不重叠
