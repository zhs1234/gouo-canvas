# Logo 与品牌套件

## 1. 品牌简报（先问，最多 4 个）

用户信息不足时一次性问，给出可选项方便回答：

1. **品牌名和行业**：名称逐字确认（含大小写、中英文写法）
2. **个性关键词**：如 温暖、专业、俏皮、克制、先锋（选 2–3 个）
3. **标志类型**：图形标、字标（只用文字）、首字母组合、图形 + 文字
4. **颜色偏好或禁忌**：已有品牌色？有不能用的颜色或元素吗？

用户说“你看着办”时，按行业常识选定方向，并用一句话说明。

## 2. 写 Logo 提示词

```
用途：Logo 设计
主要需求：为 <行业> 品牌 “<品牌名>” 设计原创标志，<个性关键词>
标志类型：<图形标 / 字标 / 首字母组合 / 图形 + 文字>
风格/媒介：矢量感标志，扁平色块，极简
构图：单个标志居中，纯白背景，四周留白充足
配色：<1–2 个颜色，高对比；有品牌色时写 hex>
图内文字（逐字）：“<品牌名>”（仅字标或图形 + 文字时）
约束：轮廓强，负空间平衡，缩小到很小也能识别；原创，不模仿任何已有商标；非必要不用渐变；不做样机、不做 3D、不加阴影和质感；无水印
```

要点：

- **简单优先**：少细节、少笔画、少颜色。装饰性花纹只有用户要求时才加。
- **小尺寸可读**：要求“在小尺寸下依然清晰”；字标的字距均匀、笔画不要过细。
- **原创**：不要参考或模仿真实品牌的标志，不用“像某某品牌那样”的描述；名称与知名商标高度相似时提醒用户注意商标风险。
- **背景**：当前没有透明背景参数。要求纯白（或纯色）背景、边缘干净，告诉用户需后期抠图或矢量化。生成的是位图，正式使用建议由设计师矢量重绘。
- 图文结合的 Logo 文字要短；中文字标写明字形风格（如“现代粗黑体，笔画末端圆角”）。

## 3. 多方向并排比较

- **省钱探索**：一张图里用 2×2 网格展示 4 个明显不同的方向（如 几何图形、首字母、具象图形、纯字标），每格一个，同样的白底和留白。这只算一张图。
- **单独出图**：每个方向一个 `create_image_task`，便于后续分别细化。张数以用户要求为准，不要擅自多出。
- `params.n` 生成的多张共用同一提示词，只适合同一方向下的随机变体。
- 用户选定方向后，每次只改一处细化（线条粗细、比例、颜色），并重复其余约束。

## 4. 品牌套件

Logo 定稿后，和用户一起填写这份模板（留空的项可以不写）。之后所有与该品牌相关的提示词都**原样复用**相关段落，保证视觉一致：

```
品牌套件：<品牌名>
品牌色：
- 主色：<名称> #<hex> —— 用于 <大面积背景 / 标题>
- 辅色：<名称> #<hex> —— 用于 <次要元素>
- 点缀色：<名称> #<hex> —— 用于 <按钮、强调>
- 中性色：深 #<hex>，浅 #<hex> —— 文字与底色
字体风格：
- 标题：<如 几何无衬线粗体，字距略紧>
- 正文/副标题：<如 人文无衬线常规体>
Logo 规则：
- 标志周围至少留出 <标志高度的一半> 的空白
- 只放在 <白色 / 主色> 背景上；不拉伸、不旋转、不改色、不加描边和阴影
- 最小使用尺寸：<如 宽度不小于 24px>
视觉风格：<摄影 / 插画；光线；质感关键词>
禁用元素：<如 渐变、霓虹色、卡通形象、竞品常用的颜色>
```

复用方式：在提示词中加入“配色：主色 #…，辅色 #…，点缀色 #…；标题字体风格：…；禁止：…”。需要把 Logo 放进物料时，把 Logo 定稿图放进 `inputImageIds`，写明“图1 是品牌标志，保持图形、比例和颜色完全不变，只放在 <位置>”。

## 5. 提交

- 不确定可用尺寸时不填 `size`；Logo 通常用方图。
- 文字较多的组合标或品牌套件展示板可用 `quality: 'high'`。
- `output_format` 用 `png` 更利于后期抠图。

## 提交前检查

- [ ] 品牌名逐字确认
- [ ] 扁平、简洁、负空间平衡，写了小尺寸可读
- [ ] 纯白背景，不做样机和 3D
- [ ] 没有模仿真实商标
- [ ] 张数与用户要求一致；多方向优先用一张网格图探索
